# 工具测试

日常使用白泽只需要 Node.js 22+，不用安装 npm 包或 Python。

## Node 测试

在 Skill 目录运行：

```text
node tests/run.mjs
```

测试代码也只使用 Node.js 内置模块。涉及 Git 的测试会创建临时仓库，所以跑完整测试需要 Git；普通静态检查和按关键词反查不要求 Git。

`tests/node/fixtures/` 保存从 Python 原版生成的固定期望值，Node 测试直接读取它们，不启动 Python。覆盖包括文档解析、中文排版、Unicode 字宽与 casefold、锚点、接口、跳转、自动修复、Git 改动反查以及 Windows 路径边界。

## 固定测试数据

Python 旧实现、pytest 测试和差分验证入口已删除。迁移时生成的 JSON 期望值继续用于 Node 回归，不依赖原实现或 Python 环境。

字宽、单词、数字和大小写折叠固定使用 Unicode 15.1.0 数据，与迁移前的 Python 3.13 基准一致，不随本机 ICU 升级变化。

## 验证边界

测试覆盖原版的静态工具行为，不代替业务链路的语义审查或实际运行验收。图形输出与原版逐字节对照，不代表已经在所有编辑器字体中完成视觉验收。Windows 路径分支用 Windows 路径规则和模拟文件系统覆盖；本轮没有 Windows 实机验收。
